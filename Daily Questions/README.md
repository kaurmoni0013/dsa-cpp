## Conventions

- Use the same file structure as every other solution: see [TEMPLATE.md](../TEMPLATE.md).
- Name the file after the problem in `snake_case`.
- Add a row to the table above and to the [Daily Problem Log](../README.md#daily-problem-log).
- A day with no solved problem gets no commit. The record should reflect real practice, not a manufactured streak.

When this folder holds enough problems to justify splitting by sub-topic, it can be reorganised then.
